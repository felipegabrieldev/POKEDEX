<h1> 🔴 Pokédex </h1>

<p> Uma Pokédex desenvolvida como projeto pessoal para praticar os fundamentos de HTML, CSS e JavaScript. </p>

<p> O projeto apresenta informações de Pokémon de forma simples e interativa, com foco em praticar a construção de interfaces e a utilização de JavaScript no desenvolvimento Front-End. </p>

<h2> 🚀 Tecnologias utilizadas </h2>

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>

<h2> 📚 Objetivo </h2>

<p> Este projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos básicos de desenvolvimento Front-End, principalmente: </p>

<p> Estruturação de páginas com HTML </p>
<p> Estilização e responsividade com CSS </p>
<p> Manipulação do DOM com JavaScript </p>
<p> Eventos e interações com o usuário </p>
<p> Organização de arquivos e código </p>

<h2> 🖥️ Funcionalidades </h2>
<p> 📖 Visualização dos Pokémon </p>
<p> 🎨 Interface inspirada em uma Pokédex </p>
